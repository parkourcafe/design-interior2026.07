# Kora Food Hall — локальный демонстратор

Read-only демонстрация ProjectCEO с ядром Project Intelligence на реальных
источниках Kora Food Hall.

## Запуск

Из корня репозитория:

```bash
python3 -m http.server 8765 --directory public
```

Открыть:

```text
http://127.0.0.1:8765/kora-project-intelligence/
```

## Сценарий показа

1. Показать сводку: 209 физических источников, 81 локальный файл и 128 cloud placeholders.
   Все 52 кандидата `current` по архитектуре, MEP и визуализациям доступны локально.
2. Нажать этап workflow — реестр отфильтруется по связанным документам.
3. Выбрать статус «Конфликт hash/имени» — показать карантин семантически конфликтующих копий.
4. Открыть строку документа — показать provenance, SHA-256, ревизию, роль и связь с workflow.
5. Нажать проблему в Review Queue — показать документы, которые требуют решения человека.

## Граница демонстрации

Это локальный снимок, а не production-загрузка в Supabase. Актуальные кандидаты
чертежей материализованы локально и получили SHA-256; старые версии, фотографии
и часть справочных материалов могут оставаться cloud placeholders. Статус
`current` означает только кандидата на текущую выдачу; утверждение человеком не
подменяется автоматикой.

Каталог исключён из Vercel deployment через `.vercelignore`: manifest и реальные
имена файлов предназначены только для локальной демонстрации. Production UI должен
получать registry через авторизованный ProjectCEO read model.
