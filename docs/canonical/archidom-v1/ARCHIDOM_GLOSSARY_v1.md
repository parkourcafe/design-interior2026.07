# ARCHIDOM — GLOSSARY v1

| Термин | Значение | Не означает |
|---|---|---|
| Product Contract | Charter и утверждённые аддендумы | описание текущего кода |
| Technical Architecture | техническая декомпозиция в рамках Charter | изменение коммерческих обещаний |
| Execution Brief | ограниченное задание спринта | новый продуктовый контракт |
| Project Workspace | пользовательская среда проекта | папка файлов или AI-чат |
| Project Memory | структурированная память проекта | transcript чата |
| Project Graph | типизированные сущности и связи | обязательную graph database |
| Studio Memory | стандарты, defaults, templates студии | отдельную память Module 5 |
| Studio Intelligence | коммерческий пакет/shared settings | доменный Module 5 |
| ProjectFact | надтип факта проекта | отдельная пятая категория рядом с Requirement |
| Evidence | источник, версия, автор, status и confidence | красивое объяснение без источника |
| Decision | версионируемое проектное решение | текст в комментарии |
| Approval | подтверждение конкретного типа и полномочия | универсальную кнопку «Согласовать» |
| Self approval | инициатор сам подтвердил действие | независимую проверку |
| ChangeRequest | предложенное изменение | утверждённое изменение |
| ChangeOrder | изменение после review и принятия impact | первоначальный запрос |
| Baseline | действующая утверждённая версия | последний загруженный файл |
| Skill | versioned executable contract | сохранённый prompt |
| Action | контекстная запускаемая операция | свободный AI-чат |
| Workflow | persisted state machine из actions и gates | список инструкций в документе |
| cost_class | тип переменной стоимости action | пользовательский тариф |
| ai_calls | журнал фактических AI/API затрат | credit balance |
| standard_drift | событие расхождения решения с новой версией стандарта | автоматическую перезапись проекта |
| Integration Gateway | общий слой connectors/adapters | MCP-only архитектуру |
| ГлавПрораб | публичное имя M4 | Site Manager в публичном UI |
