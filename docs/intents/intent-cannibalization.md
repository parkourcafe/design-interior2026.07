# Cannibalization Risk Analysis

## Overview

This analysis identifies intents that might compete for the same search traffic or user attention.

## Risk Assessment

### Low Risk Intents

Most intents have low cannibalization risk because they target different user segments and distinct goals:

**Designer Intents:** Each intent represents a distinct phase in the project workflow (collect info → structure → identify risks → calculate price → prepare proposal → manage expectations).

**Client Intents:** Each intent addresses a specific concern or question in the buyer journey (choose designer → understand cost → learn process → agree on terms).

**Studio Intents:** Focus on management and analytics, distinct from designer workflow intents.

### Potential Overlaps

- DESIGNER_001 (Собрать информацию) and CLIENT_010 (Понять процесс) may have slight overlap in search intent, but serve different audiences (supply vs. demand).
- DESIGNER_003 (Рассчитать цену) and CLIENT_002 (Понять стоимость) address the same topic but from different perspectives.

### Mitigation Strategy

- Use clear audience targeting in metadata (designer vs. client)
- Differentiate content by perspective and use case
- Use internal linking to connect related intents
