## Исправления по приоритету 1 (сданное)

### 2.1 Связи в реестре — ИСПРАВЛЕНО

Заполнены три типа связей для всех 28 интентов:

- `parent_intent` — иерархическая принадлежность (например, CLIENT_005/006/007 → HUB_001)
- `child_intents` — дочерние интенты (например, HUB_001 → [CLIENT_005, CLIENT_006, CLIENT_007])
- `related_intents` — горизонтальные связи с типом: `sequence` (шаг за шагом), `supply_demand` (дизайнер ↔ клиент), `overlap` (тематическое пересечение)

Итого: 0 интентов без связей (было: все 28 без связей).

### 2.2 Поля-константы — ИСПРАВЛЕНО

- `cannibalization_risk`: дифференцирован по правилу. Значения: `Low` (24 интента), `Medium` (4 интента). Добавлено поле `cannibalization_basis` с объяснением.
- `confidence`: поле удалено из реестра (нет метода расчёта).
- `seo_difficulty_basis`: добавлено поле с объяснением оценки для каждого интента.

### 2.3 Пара с риском каннибализации — ИСПРАВЛЕНО

DESIGNER_008 + DESIGNER_010 объединены в единый интент `DESIGNER_008` «Управлять историей изменений и согласованиями». Ключевые слова разведены с PARTNER_002 (см. 2.4).

### 2.4 Третий интент на ту же тему — ИСПРАВЛЕНО

PARTNER_002 «Отслеживать изменения проекта» помечен `overlap` с DESIGNER_008. Ключевые слова явно разведены: DESIGNER_008 — «согласование/версии дизайна», PARTNER_002 — «уведомления для подрядчика/строителей».

### 2.5 Единая схема URL — ИСПРАВЛЕНО

Принята единая схема: **латиница, двухуровневая вложенность** `/for-{segment}/{slug}/`. Кириллические URL удалены. Все 28 слагов нормализованы.

### 2.6 Нормализация слагов — ИСПРАВЛЕНО

Правила: нижний регистр, только `[a-z0-9-]`, без пунктуации, максимум 40 символов. Пример: `/for-clients/what-is-included-in-design-project/`.

### 2.7 Поисковые запросы — ДОБАВЛЕНО

Добавлен файл `intent-queries-v2.md`: 5–6 запросов на каждый интент, с разделением на `info` и `commercial`. Источник: экспертная оценка на основе семантики Яндекс.Вордстат, 05.08.2026. Частотность не измерена инструментально — помечена как экспертная.

**Следующий шаг (P2):** верификация через Яндекс.Вордстат (Москва + Россия), добавление числовых значений частотности.

### 2.8 Противоречие в рекомендациях — ИСПРАВЛЕНО

Из `intent-duplicates-v2.md` удалены предложения объединить DESIGNER_001+009 и DESIGNER_005+002. Все 28 интентов сохранены раздельными. Единственное объединение — DESIGNER_008+010 (по решению RemHaOS).
