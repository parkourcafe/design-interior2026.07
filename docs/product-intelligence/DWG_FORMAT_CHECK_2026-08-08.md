## Результат: версии формата

```text
23 файла  AC1021   AutoCAD 2007–2009
 3 файла  AC1032   AutoCAD 2018+
```

`AC1032` — у `A01-301 Tenants`, `A01-308 Tenants`,
`A02-101 AC Room Details - Canopy Glass`. Остальное — `AC1021`.

**`AC1037` не встречается ни разу.** Опасение из §3.2 о том, что современный
AutoCAD пишет формат новее читаемого бесплатными библиотеками, на этом пакете
не подтвердилось. Обе найденные версии входят в диапазон, который заявляет
LibreDWG (до R2018 включительно).

**Вывод по пункту 1: вариант B не заблокирован форматом.** Откат на вариант A
по этому основанию не требуется.

## Чего эта проверка НЕ доказала

Прочитаны первые шесть байт каждого файла — это версия контейнера, а не
успешный разбор. Реальный парсинг бесплатной библиотекой в этой сессии не
выполнялся: LibreDWG отсутствует в репозиториях окружения, сборка из исходников
за рамками проверки.

Существенная оговорка, а не формальность: доминирующая здесь версия `AC1021`
(R2007) исторически самая проблемная для LibreDWG — у неё иная раскладка секций
файла, и поддержка именно этой версии традиционно слабее, чем у соседних. То
есть «версия в диапазоне» здесь — необходимое условие, но заметно менее
достаточное, чем было бы для R2010 или R2013.

Поэтому пункт 1 §3.2 закрыт, а общая проверка — нет.

## Что осталось по §3.2

1. **Разбор живого файла** бесплатной библиотекой в окружении, где она
   доступна. Целевой файл — `A01-201 First Floor Layout.dwg` (578 КБ,
   `AC1021`): это планировка этажа, то есть ровно тот класс чертежа, который
   пойдёт в подложку. Достаточный критерий для подложки — извлечь геометрию
   настолько, чтобы линии читались глазом; полнота не требуется.
2. **Качество DXF в обе стороны** — слои, блоки, тексты, размеры, кириллица.
   В самом пакете DXF нет, так что материал для этой проверки нужно получить
   отдельно либо сгенерировать конвертацией из этих же файлов.

До выполнения пункта 1 реализация подложки не начинается — §3.2 в силе.

## Побочное наблюдение

Пакет состоит из отдельных чертежей по дисциплинам с осмысленной нумерацией
(`A01-201`, `E04-101`, `P02-100`), рядом с каждым лежит `.bak`. Это обычная
рабочая практика подрядчика. Для подложки это означает, что дизайнер будет
выбирать конкретный лист из десятков, а не «загружать проект» — сценарий выбора
листа надо предусмотреть в интерфейсе с самого начала.
