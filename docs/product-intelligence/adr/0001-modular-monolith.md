# ADR-0001: Модульный монолит до подтверждённого масштаба

Статус: accepted. Дата: 16 июля 2026.

## Контекст

Команда должна проверить один повторяемый платный workflow, сохранив общую доменную модель для двух редакций. Микросервисы увеличат стоимость транзакций, миграций, observability и локальной разработки раньше, чем появится нагрузка или несколько автономных команд.

## Решение

Использовать модульный монолит с явными bounded modules, typed application services и одной PostgreSQL database на deployment cell.

## Последствия

- проще сохранить транзакционность graph/version/impact;
- быстрее выполнять additive migrations и пилоты;
- границы модулей должны проверяться code review/tests, а не сетью;
- выделение сервиса разрешено отдельным ADR при измеренной причине.
