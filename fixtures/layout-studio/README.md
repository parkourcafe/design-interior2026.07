# Synthetic Layout Studio fixtures

`liquid-station.synthetic.v0.1.json` — полностью синтетический документ для
автоматических тестов ArchiDom Layout Studio.

Он **не является KORA evidence**, не воспроизводит фактические координаты,
габариты, имена файлов или manifest проекта KORA и не должен использоваться как
строительная документация. Все ссылки на происхождение начинаются с `synthetic:`;
в fixture нет PII, абсолютных путей, private URL или production credentials.

Fixture намеренно содержит замкнутый прямоугольный контур, две двери, отдельную
колонну 250 × 250 мм, стойку, двойную мойку, оборудование, стабильные material IDs
и два разных источника света. Канонические линейные значения заданы целыми
миллиметрами.
